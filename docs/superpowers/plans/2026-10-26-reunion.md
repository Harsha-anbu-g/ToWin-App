# Reunion Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A "Reunion" section where an elder wishes to meet old classmates or colleagues, picks a trusted organiser, and the two walk seven numbered steps to a send-off where every guest is confirmed home.

**Architecture:** Backend package `com.towinly.reunion` (entities, service with every rule, thin controller, migration V64) on branch `feat/reunion`. App: `src/api/reunions.js` as the tool catalog, `src/lib/reunionSteps.js` as the shared vocabulary, six small components, two routes, one Profile row, translations, MCP snapshot.

**Tech Stack:** Spring Boot 3 / Java 21 / Flyway / Mockito; React Native (Expo SDK 54, expo-router, TanStack Query, Jest + RNTL 14).

Spec: `docs/superpowers/specs/2026-10-26-reunion-design.md`. The code in each task is written in the repo as the task runs; this plan names the files, the tests and the commands.
